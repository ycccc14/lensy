# Lensy 美瞳记录

手机网页 App（PWA），可在 iPhone / Android 上“添加到主屏幕”像 App 一样使用，离线可用。所有资料只存在手机里（IndexedDB），可导出 / 导入 JSON 备份。

## 功能
- **录入美瞳**：选品牌 → 选花色（可按色系筛选）→ 选周期。只有核对过品牌官网的款式（ACUVUE DEFINE、FreshKon）会自动填参数；其他款式不填“参考值”，表单里有「淘宝查参数」「小红书查」按钮，照售卖页填一次，下次同款自动填好。可记录度数、有效期、价格（MYR / CNY / AUD）、渠道，照片分「我的佩戴效果」和「网图」。编辑时可以改剩余片数和买入片数。
- **库存**：按片数记录，日抛“今天戴这副”自动扣 2 片（可设单眼 1 片），+/− 和“+1盒”补货。
- **开封 & 到期**：双周/月/季/半年/年抛记录开封日期，到期前 N 天提醒，可自定到期日。
- **换护理液提醒**：不戴的时候按间隔（默认 3 天，可每副单独设）提醒换水；戴过摘下自动算作已换。
- **佩戴计时**：戴上 / 摘下，超过建议时长提醒；可补记过去的佩戴。
- **存档**：用完、丢弃、不喜欢的美瞳和每一副的开封→丢弃记录都保留。
- **心愿单**：4:3 网图、价格、链接、想要程度；点开看全部图片、资料和风格 & 搭配建议，右上角“编辑”；“买到了”一键转成美瞳记录（图片归到网图）。
- **货币**：价格可以用 MYR / CNY / AUD 输入（CNY × 0.6 = MYR，AUD × 2.8 = MYR），总花费按“我的 → 总花费显示为”选的货币显示。
- **风格 & 妆容建议**：按色系、着色直径、花色名自动生成风格标签、眼影/腮红/唇色色卡、场合、发色穿搭，并一键打开小红书搜索“上眼图 / 妆容 / 同色系”（App 和网页版），可收藏小红书链接和截图。
- **护理品**：护理液、双氧水、眼药水、镜盒等，按“有效期”和“开封后可用天数”中较早的一个提醒。眼药水可选使用周期，默认日抛（单支装：记支数，“用了一支”扣一支，剩 5 支提醒补货）。
- **统计**：佩戴日历、累计次数、平均时长、总花费、每次成本、最常戴、色系偏好。
- **手机通知（App 关着也会提醒）**：“我的 → 手机通知 → 开启”。手机把接下来的提醒（时间 + 文字）交给 Lensy Push 服务器（`server/Code.gs`，Google Apps Script，每 15 分钟检查一次），到点用 Web Push 推到手机；推送本身是空的，手机收到后再从服务器取文字。到期日/换水日在“每天提醒时间”（默认 09:00）推送，戴太久按戴上时间 + 最长佩戴小时推送。iPhone 需 iOS 16.4+，并从主屏幕打开 Lensy。也可以导出 .ics 到手机日历。
- **自动更新**：每次打开（或切回）App 都会检查新版本，有就在后台下载并自动刷新到最新版（正在填表时等关掉表单再刷新）。
- **只能上下滑**：不能左右滑、不能缩放、不显示滚动条；日期框等每个输入框都在自己的格子里。

## 说明
- 内置参数是品牌系列的常见参考值，请以包装为准。
- 小红书没有开放接口且禁止抓取，所以建议是在手机上自动生成的，真人上眼图通过一键搜索打开小红书查看。
- 推送服务器第一次需要在 Apps Script 编辑器里运行一次 `setup` 并授权（https://script.google.com/d/1VLbB6Rr_vkXchlz7qb6EQ7h-7iHFqDXeJ5x9lv10C0tegQJEHTTAbdqt/edit）。服务器只保存每台手机的推送地址、接下来的提醒文字和一个密钥的哈希。

## 开发
```
.\deploy.ps1 "改了什么"     # 先跑全部测试，通过才发布到 GitHub Pages
node test/server.js          # http://localhost:8790/
node test/logic.test.js      # 提醒、推送时间表、货币、眼药水、品牌库、妆容建议、日历导出
node test/push-server.test.js # 推送服务器（VAPID 签名、到点推送、收件箱）
node test/ui-test.js         # iPhone 尺寸的无头 Chrome 实测，截图在 test/shots/
node test/layout-test.js     # 320–430px 每个页面和弹窗：文字不出框、不横向滚动、不能缩放
python tools/make-icons.py   # 重新生成图标
```
改了任何文件后，把 `sw.js` 和 `js/app.js` 里的 `VERSION` 加一，手机下次打开就会自动更新。deploy.ps1 也会把 `server/` 推到 Apps Script 并更新同一个网址的部署。
