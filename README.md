# Lensy 美瞳记录

手机网页 App（PWA），可在 iPhone / Android 上“添加到主屏幕”像 App 一样使用，离线可用。所有资料只存在手机里（IndexedDB），可导出 / 导入 JSON 备份。

## 功能
- **录入美瞳**：选品牌 → 选花色（可按色系筛选），自动填写直径、着色直径、基弧、含水量、每盒片数；同一花色有多种周期时让你选买的那种。可记录度数、产品有效期、价格、渠道、多张照片。内置 13 个品牌；不在库里的品牌/花色直接输入，Lensy 会记住，下次自动补齐。
- **库存**：按片数记录，日抛“今天戴这副”自动扣 2 片（可设单眼 1 片），+/− 和“+1盒”补货。
- **开封 & 到期**：双周/月/季/半年/年抛记录开封日期，到期前 N 天提醒，可自定到期日。
- **换护理液提醒**：不戴的时候按间隔（默认 3 天，可每副单独设）提醒换水；戴过摘下自动算作已换。
- **佩戴计时**：戴上 / 摘下，超过建议时长提醒；可补记过去的佩戴。
- **存档**：用完、丢弃、不喜欢的美瞳和每一副的开封→丢弃记录都保留。
- **心愿单**：带图、价格、链接、想要程度；“买到了”一键转成美瞳记录。
- **风格 & 妆容建议**：按色系、着色直径、花色名自动生成风格标签、眼影/腮红/唇色色卡、场合、发色穿搭，并一键打开小红书搜索“上眼图 / 妆容 / 同色系”（App 和网页版），可收藏小红书链接和截图。
- **护理品**：护理液、双氧水、眼药水、单支润眼液、镜盒等，按“有效期”和“开封后可用天数”中较早的一个提醒。
- **统计**：佩戴日历、累计次数、平均时长、总花费、每次成本、最常戴、色系偏好。
- **从 iPhone「提醒事项」导入**：用一个快捷指令把清单（标题、备注里的周期、是否已勾选、图片）导出成文件，在“我的 → 从提醒事项导入”选它；先预览、可改品牌/花色/去向，再一键导入。写了周期的进美瞳柜，没写的进心愿单，已勾选的美瞳存档，已有的自动跳过。也可以直接粘贴文字（不含图片）。快捷指令的设置步骤在 App 里。
- **提醒方式**：首页提醒列表；开启通知后打开 App 时推送并显示图标数字；导出 .ics 到手机日历（不开 App 也会准时响）。

## 说明
- 内置参数是品牌系列的常见参考值，请以包装为准。
- 小红书没有开放接口且禁止抓取，所以建议是在手机上自动生成的，真人上眼图通过一键搜索打开小红书查看。
- 网页 App 无法在后台自己定时弹通知（iPhone 尤其如此），所以可靠的到点提醒用“导出到日历”。

## 开发
```
.\deploy.ps1 "改了什么"     # 先跑全部测试，通过才发布到 GitHub Pages
node test/server.js          # http://localhost:8790/
node test/logic.test.js      # 提醒、品牌库、妆容建议、日历导出
node test/ui-test.js         # iPhone 尺寸的无头 Chrome 实测，截图在 test/shots/
python tools/make-icons.py   # 重新生成图标
```
改了任何文件后，把 `sw.js` 里的 `VERSION` 加一，手机才会拿到新版本。
